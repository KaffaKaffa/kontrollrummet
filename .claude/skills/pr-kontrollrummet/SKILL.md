# PR mot det publika repot

Kontrollrummets kod ligger publikt på https://github.com/KaffaKaffa/kontrollrummet. Allt som
pushas dit kan läsas, kopieras och sparas av vem som helst, för alltid: en commit som tas bort
finns kvar i forks, cachar och arkiv. Därför granskas varje ändring innan den lämnar datorn.

## Det som aldrig får med

- **Namn på personer.** Inte kollegor, kunder, granskare, testare eller ägaren själv, inte heller
  i kodkommentarer, exempel, testdata eller commit-meddelanden. Behövs ett exempel: hitta på ett
  (Kim, Alex, Sam) eller skriv utan namn ("väntar på en granskare"). Agenters smeknamn som en
  användare gett dem räknas också som privata.
- **Kunder, projekt och organisationer** som kontrollrummet används för: deras namn, repo-namn,
  Azure-organisationer, domäner, app-id:n och adresser till deras tjänster.
- **E-postadresser och konton**, utom `example.com` och GitHubs `users.noreply.github.com`.
- **Hemmappar och sökvägar** från den här datorn (`/Users/…`, `C:\Users\…`). Skriv `~/…`.
- **Nycklar, tokens, lösenord och certifikat**, även gamla eller "bara test". En nyckel som
  pushats publikt är läckt: den måste bytas hos tjänsten, att ta bort committen räcker inte.
- **Interna adresser:** IP-nummer i lokala nät, interna värdnamn, VM-namn.
- **Innehåll ur projekten:** `teams/*` (utom `teams/README.md` och exemplet), porträtt per
  projekt (`web/public/avatars/`), loggar, skärmdumpar, kort och konversationer.
- **Stora binärfiler** (över 5 MB). Meshys råfiler ligger kvar lokalt (se `.gitignore`).

## Så görs det

1. **Gren från publika main.** `git fetch origin` och `git switch -c <kort-gren> origin/main`
   (eller fortsätt på samtalets gren om den redan utgår därifrån). Grennamn på svenska, utan namn.
2. **Commits.** Svenska, kort ämnesrad som säger vad användaren märker. Ingen AI-attribution:
   inga `Co-Authored-By`, ingen "generated by"-rad. Inga namn eller kunder, inte ens som exempel.
3. **Skriv PR-beskrivningen till en fil** i scratchpad, inte i repot. Samma regler som ovan.
4. **Granska.** Kör
   `node scripts/check-public.mjs origin/main --text <pr-beskrivningen>`
   Skriptet läser privata ord ur den här datorns projekt och konton, och letar efter adresser,
   hemmappar, nycklar och stora filer i allt som lagts till, i commit-meddelandena och i
   beskrivningen. Varje träff åtgärdas: anonymisera eller ta bort, skriv om commit-meddelanden
   (`git commit --amend`, eller samla grenen till en commit). Kör igen tills det står
   "Inget privat hittat". Ett falsklarm (ett vanligt ord som råkar vara ett projektnamn) går
   bara att släppa förbi efter att ha tittat på raden; säg i så fall vilket ord och varför.
5. **Läs själv också.** Skriptet känner bara till det som står i den här datorns konfiguration.
   Titta igenom diffen efter namn den inte vet om: kollegor i exempel, kunders produktnamn,
   skärmdumpar med data.
6. **Typkontroll och bygge.** `npm run typecheck` och `npm run build` ska gå igenom.
7. **Pusha och öppna PR:en.**
   `git push -u origin <gren>` och
   `gh pr create -R KaffaKaffa/kontrollrummet --base main --title "<titel>" --body-file <fil>`
   Titel och beskrivning på svenska, utan AI-signatur.
8. **Merga inte själv.** Ge länken till PR:en. Ägaren mergar.

Har något privat redan pushats: stoppa, säg det direkt, och föreslå vad som måste göras
(byta nyckeln hos tjänsten, skriva om historiken, be GitHub rensa cachen). Gör inget av det
utan att ägaren sagt ja.
