# Kontrollrummet

Regler för den som arbetar i kontrollrummets egen kod: Gudfadern, en Claude Code-session eller en människa.

## Repot är publikt

Koden ligger öppet på https://github.com/KaffaKaffa/kontrollrummet (`origin`). Allt som committas kan
hamna där och gå inte att ta tillbaka.

- **Inga riktiga namn.** Inte på kollegor, granskare, kunders personal, ägaren eller agenternas
  smeknamn, inte heller i kodkommentarer, exempel, tester eller commit-meddelanden. Ta inte exempel
  ur skärmdumpar eller riktig data. Behövs ett exempel: hitta på (Kim, Alex, Sam), eller skriv utan namn.
- **Inga kunder eller projekt** som kontrollrummet används för, inga e-postadresser, hemmappar
  (`/Users/…`), interna adresser eller nycklar.
- **Inget ur `teams/`** (utom `teams/README.md` och exemplet) och inga porträtt per projekt.
- **PR:er** görs med skillen `pr-kontrollrummet`, och `npm run check:public` ska vara rent innan
  något pushas.

## Arbetssätt

- Texter i appen, commit-meddelanden och PR:er på svenska. Kod och kodkommentarer på engelska.
- Ingen AI-attribution i commits eller PR:er: inga `Co-Authored-By`, ingen "generated by"-rad.
- `npm run typecheck` och `npm run build` ska gå igenom.
- Servern startas om med knappen i appen (eller `POST /api/restart`), som väntar tills agenter och
  byggen är klara. Döda den aldrig mitt i ett bygge.
