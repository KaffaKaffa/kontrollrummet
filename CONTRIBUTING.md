# Bidra

Kul att du vill bidra. Kontrollrummet är skrivet på svenska: texter i appen, commit-meddelanden
och PR:er skrivs på svenska. Kod och kodkommentarer på engelska.

## Innan du öppnar en PR

- `npm run typecheck` och `npm run build` går igenom.
- `npm run check:public` hittar inget. Det letar efter det som inte hör hemma i ett publikt
  repo: namn på personer och kunder från dina egna projekt, e-postadresser, hemmappar,
  interna adresser, nycklar och stora filer.
- Inga riktiga namn, inte ens som exempel i kommentarer eller tester. Hitta på (Kim, Alex)
  eller skriv utan namn.
- Inget ur `teams/`, utom `teams/README.md` och exemplet. Dina projekt är dina.
- En PR gör en sak, och beskrivningen säger vad användaren märker.
