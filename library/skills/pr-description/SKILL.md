# PR-beskrivning

Skriv på svenska, utan AI-signatur:

- **Titel:** vad PR:en gör, i imperativ, under 70 tecken.
- **Varför:** problemet eller behovet, med länk till kort eller ärende.
- **Vad:** ändringarna i punktform, grupperade per del av kodbasen.
- **Så testade jag:** kommandon och manuella steg, och vad som inte är testat.
- **Att titta på:** det granskaren bör se extra noga på, och risker.
- Skärmdumpar för UI-ändringar.
